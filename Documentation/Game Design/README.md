# Game Design

This folder collects design notes for game projects built with Arcadia. Use this file as the common entry point before
opening a specific subfolder.

## Folders

- `Scenario I/`: fiction, setting truth, factions, room vocabulary, art direction, and key scenes for the current game
  scenario.
- `Game Mechanics I/`: player verbs, interaction modes, resources, progression, reboot/reset logic, and other system design
  for the current mechanics exploration.
- `Production I/`: implementation-facing planning for turning the scenario and mechanics into a playable executable, including
  technical requirements and UI implementation direction.

## Reading Order

1. `Scenario I/README.md`
2. `Scenario I/Setting Truth.md`
3. `Game Mechanics I/README.md`
4. `Game Mechanics I/Interaction Model.md`
5. `Game Mechanics I/Progression Model.md`
6. `Production I/Technical Requirements.md`
7. `Production I/UI Direction.md`

## Terms

In this documentation, `production` means game-development execution: the practical work of turning scenario and mechanics
documents into buildable, playable software. It does not refer to the in-world production mechanic or resource fabrication.
