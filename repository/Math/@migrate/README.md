# Legacy Math migration inventory

The `1/`, `2/`, and `3/` directories are historical versions of the old
`dx/core/math.h` and `math.c`. They are **not** production inputs. They share
legacy header guards and depend on obsolete `dx` / `Core` types; do not
register them with Arcadia's CMake targets.

## Already migrated

- Signed-extent 2D rectangles and their union/translation operations:
  `Arcadia_Math_Rectangle2Real32` and `Rectangle2Real64`.
- 2D, 3D, and 4D vector arithmetic, component-wise multiplication,
  interpolation, and zero-tolerant normalization: generated by
  `Arcadia/Math/Implementation/Vector.c.te` and `Vector.h.te`.
- 3D point transformation by a 4x4 matrix:
  `Arcadia_Math_Matrix4x4Real32_transformPoint` and its Real64 counterpart.
- Matrix construction from row-major component arrays, interpolation,
  cloning, and independent value copying: generated by
  `Arcadia/Math/Implementation/Matrix.c.te` and `Matrix.h.te`.
- 8-bit pixel value layouts, interpolation, and normalized RGB/RGBA color
  conversion: `Arcadia/Media/PixelValuesNatural8.h`.
- Native RGB Real32 value, set, equality, and interpolation:
  `Arcadia_Math_RgbReal32`.
- Degree/radian conversion and scalar clamping: modern Math / Ring APIs.
- The legacy rotation-Y point cases (0, 90, 180, 270 degrees) are now
  covered by MatrixTests for both precisions. Real64 Y-axis rotation and
  Real64 pi precision were corrected during that test migration.

The obsolete `Core.Assets.Vector3R32` and `Core.Assets.Matrix4x4R32`
wrappers were removed after their create-from-values / read-back semantics
became available in `Arcadia.Math`. The empty `getWorkingDirectory` stubs
were also removed; working-directory lookup does not belong to Math.

## Color4 generator hardening

The maintained Color4 generator now supports Real32 and Real64 argument
transport, interpolation, inversion, saturating addition, cloning and
independent component copies. ColorObjectTests verifies both precisions.

## Remaining review before removal

- `2/math.h` defines a native three-component `Core_InlineRgbR32` value,
  including set and equality helpers. This is now exported as
  `Arcadia_Math_RgbReal32`, a native, allocation-free RGB value.
  Interpolation with a clamped factor also replaces the old RGB lerp
  declaration, which lacked an implementation.
- `2/math.h` also declares the named `dx_colors_capri`,
  `dx_colors_malachite`, and `dx_colors_amber` RGB8 constants, but these
  files provide no definitions for them. Do not claim these are ported
  implementations or introduce definitions solely to satisfy dead declarations.
- The three historical versions contain duplicate, incomplete, and
  incompatible declarations; they are for migration auditing only, not for
  direct compilation.

Preserve this inventory only while the three historical source directories
remain. Once their unique declarations have been resolved, remove the
remaining archive and this README together.
