# ADL Maintenance Notes

## Ownership And Includes

- Public consumers include `Arcadia/ADL/Include.h`. The aggregate scopes `ARCADIA_ADL_PRIVATE`; retain the separate EXPORT convention. Do not restore `ARCADIA_ADL_MODULE` or bypass another module's private guards.
- The Arcadia.ADL PDL module owns five generated enums and five generated definition classes. Their inputs are registered in `Library/CMakeLists.txt`; normal builds compile committed outputs, while explicit PDLC invocation regenerates them. Follow root regeneration instructions and the per-class workflow in `Engine/AGENTS.md`.
- Definition/Definitions, Context, Reader, Reference, reference resolution and reference-bearing definition implementations remain native. Opaque native imports do not own their headers/bodies. Definition's PDL constructor/link metadata describes only the native boundary, not regenerated base storage or visitors. Same-module mappings avoid aggregate cycles; foreign dependencies use ADL's master header.
- Media DSP implementations are excluded from the migration scope; ADL DSP definition/configuration objects are distinct asset objects, not sample algorithms. Do not use their generated implementation as authorization to port Media DSP.

## Preserved Contracts

- TextureFilter and TextureAddressMode retain their `None = 10` sentinels. Reader rejection of explicit None strings is separate from the enum's existence and omitted-property defaults.
- MaterialType retains BlinnPhong=0. AmbientColorSource retains Mesh/Vertex/Texture/TextureVertex=0/1/2/3; it is not Engine's three-way ColorSource. Native MaterialNode retains the TextureVertex program flag while mapping to Engine Texture at the backend boundary. BlendFunction preserves eleven values, including None=10; source/destination choices are independent.
- ColorDefinition has Natural8 fields red/green/blue/alpha in that order. Its five-argument factory and runtime constructor still accept only definitions/name/R/G/B and initialize alpha to 255 via the PDL-owned constructor's defaultAlpha binding (ColorDefinitionRuntime.c supplies only the typed constant). Reader alpha is optional, presence-sensitive and uses RGB's Natural8 conversion semantics; explicit zero stays zero. Keep the inherited no-op link, managed parent fields, legacy RGB offsets/layout checks and factory signature; do not invent getters, slots, premultiplication or blending defaults. Media fills intentionally stay opaque, geometry conversion and example clear/text colors retain alpha 1, and UI Button retains RGB-only state. VisualsColorAlpha* and ColorModel cover these storage/default/error/GC/graph/legacy-asset contracts, not visual transparency.
- WhiteNoiseDefinition adds no field, ConstantDefinition owns Real32, and SineWaveDefinition/SawtoothWaveDefinition own signed Integer32 frequencies with nonvirtual getters. Preserve signed zero, infinities/NaNs and the full signed frequency domain; do not add clamping or positivity restrictions based on old prose.
- Constructor arity must be validated before reading/forwarding superclass arguments. Otherwise wrong counts above caller stack values can produce ArgumentTypeInvalid instead of NumberOfArgumentsInvalid. Keep required definitions/name validation and native superclass visitation intact.

## Regression Coverage And Known Limits

- Read `AGENTS/Testing.md`. Extend existing `Tests/Definitions` named cases rather than adding permanent per-enum/class executables. ClassModels.c retains ABI, factory/dispatch, arity/tag, native descendant, GC/finalization, callback failure and deep-stack cleanup coverage. Temporary Native/Generated providers are retired only after the migration gates pass.
- VisualsTextureEnums and VisualsMaterialEnums establish parsing/factory/enum transport and GC behavior, not backend rendering equivalence or material/reference graph lifetime. Preserve distinct U/V, magnification/minification and source/destination values so swaps are detected.
- Use DSPSineWaveDefinition or SineWaveModel; DSPSineWaveDefinitionRepeat was an identical fresh-process workload and is retired without an alias.
- MaterialDefinition's native visitor must trace ambientColorTexture. VisualsMaterialDefinition2 keeps only the material strongly rooted, observes the Reference weakly, forces collection before/after linking, and verifies release after dropping the material root. This regression is separate from scalar material-enum coverage; keep the reference-bearing implementation native.
- Broad Reference/Definitions/Context/Reader, graph expansion/linking and material/mesh/UI-family migrations remain deferred pending their own ownership, resolution, cycle/cache and partial-progress audits.

## Graph Composition

- The current graph surface and limits are documented in `Documentation/Specification/9. Graph composition.i` and `Documentation/Module-Interface/Graphs.i`. Graph-local DSP.Mix is explicitly registered alongside DSP.SineWave; its required nonempty inputs list uses the reference-list descriptor and accepts only those two local DSP types. Preserve input order and duplicates during expansion, distinct instance-local definitions, and the single published output. Definitions' GraphsDual* cases cover ordered identities, twelve declaration permutations, SampleBuffer linking, independent instances, GC and template-only negatives. Ordinary Gain/LowPass reader support does not authorize graph-local registration. Media DSP remains native; this is source expansion, not a new mixer or render-equivalence claim.
- GraphCollector records reference edges with non-void presence markers; HashMap treats void values as removal. Preserve the output-source, sine-frequency, descriptor-single and descriptor-list collection paths. Definitions' GraphsUnresolved*, GraphsWrong*Family, GraphsOutputReference, GraphsSelfCycle and GraphsCrossCycle cases reject invalid templates directly through the collector (without reader/linker failures masking validation); GraphsRetainedEdges covers duplicate references and collector-owned node lifetime across GC. Reference parameters remain Color-only; output/source type equality and new frequency policy require separate decisions. FillOperation still has no reference-field descriptor; do not infer complete field coverage from its accepted type name.
- Instance binding/expansion staging precedes generated-node reading, but ordinary batch nodes are read first and generated nodes are then published one at a time. Do not promise whole-batch rollback or failure atomicity for reader/allocation/publication errors. Graph expansion does not define audio clipping or cross-platform sample determinism.
