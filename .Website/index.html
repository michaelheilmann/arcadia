The idea

A game is a set of text documents, not a binary.

Those documents describe the game's visuals, audials, and logics in plain, editable prose and markup, and Arcadia regenerates the whole game from them whenever it is needed. Nothing is lost that only a compiler or a level editor ever knew.

What that leaves you with is something you can read, diff, share, and hand to the next person. Not just something you can run.

What that buys you

Portable — the descriptions carry no platform assumptions, so a game travels to another platform without being rewritten for it.

Regenerable — deterministic procedural generation rebuilds rich worlds, sounds, and behaviour from compact text.

Preservable — the description is the artifact. It outlives the engine, the platform, and often the person who wrote it.

Self-publishing — Arcadia emits each game as a complete, self-contained website, ready for a static host or for reading offline.
