Michael Heilmann's Arcadia ADL Module Interface

This is the documentation for Michael Heilmann's Arcadia ADL. The module defines

  • the context and the reader registry that process ADL assets,
  • the container of definitions and the base definition and reference types, and
  • the definition types of the assets an Arcadia application loads: colors, meshes, models, materials, pixel buffers, pixel-buffer operations, textures, sample buffers, and digital signal processing definitions.

Module Interface

Arcadia_ADL_Context

Arcadia_ADL_Context A context is a registry of readers, mapping the string type of an ADL asset to the reader that processes it.

A context is a singleton: there is exactly one context per process. It is created on demand by Arcadia_ADL_Context_getOrCreate. Reading an asset whose type entry is not served by any registered reader raises a semantical error.

Arcadia_ADL_Reader

Arcadia_ADL_Reader A reader validates the assets of a definition type against their schema and constructs the resulting definitions.

The Arcadia.ADL.Reader type is the base type of the concrete readers of the module, one per definition type. A reader lives in the context registry and is looked up by the string type entry of an asset. Applications normally do not call the methods of a reader directly; they read assets through a context.

Each concrete reader owns the schema of its type, given in the Arcadia Data Definition Schema Language (Arcadia DDLS), and validates every asset against it before constructing the definition.

Arcadia_ADL_Definition

Arcadia_ADL_Definition A definition, the base type of all definitions of the Arcadia asset definition language.

A definition has a name and belongs to a container of definitions. Some definitions hold references to other definitions; such references are resolved when the definition is linked (see Arcadia_ADL_Definition_link and Arcadia_ADL_Definitions_link).

Arcadia_ADL_Reference

Arcadia_ADL_Reference A reference of a definition to another definition, by name.

While an asset is being read, a reference holds the name of the referenced definition but not the definition itself. Resolving the reference looks the name up in the container of definitions. References are resolved when the owning definition is linked.

Arcadia_ADL_TextureDefinition

Arcadia_ADL_TextureDefinition The definition of a texture: a pixel buffer sampled with a magnification filter, a minification filter, and a texture address mode for each texture coordinate.

The type name of the definition, used as the type entry of an ADL asset, is "Texture". The texture holds a reference to the pixel buffer it samples, resolved when the definition is linked; the referenced definition must be a PixelBuffer definition.

The sampling properties magnificationFilter, minificationFilter, addressModeU, and addressModeV are optional. The value None is the default value and indicates that the sampling property is not specified, in which case the default of the engine is used.

Arcadia_ADL_BlendFunction

typedef enum Arcadia_ADL_BlendFunction Arcadia_ADL_BlendFunction; An enumeration of blend functions. A blend function identifies the factor the source or the destination color is multiplied with when blending is enabled. The values correspond to the blend functions of the engine and to the blend factors of OpenGL.

The value None is used as the default value and indicates that blending is disabled and hence no blend functions are applied. In ADL assets, each element is identified by a string literal of the same name, e.g. "Zero" or "SourceAlpha".

Elements

Arcadia_ADL_BlendFunction_None
Blending is disabled. This is the default value.
Arcadia_ADL_BlendFunction_Zero
The factor (0,0,0,0).
Arcadia_ADL_BlendFunction_One
The factor (1,1,1,1).
Arcadia_ADL_BlendFunction_SourceColor
The factor is the color of the source.
Arcadia_ADL_BlendFunction_OneMinusSourceColor
The factor is one minus the color of the source.
Arcadia_ADL_BlendFunction_DestinationColor
The factor is the color of the destination.
Arcadia_ADL_BlendFunction_OneMinusDestinationColor
The factor is one minus the color of the destination.
Arcadia_ADL_BlendFunction_SourceAlpha
The factor is the alpha of the source.
Arcadia_ADL_BlendFunction_OneMinusSourceAlpha
The factor is one minus the alpha of the source.
Arcadia_ADL_BlendFunction_DestinationAlpha
The factor is the alpha of the destination.
Arcadia_ADL_BlendFunction_OneMinusDestinationAlpha
The factor is one minus the alpha of the destination.

typedef enum Arcadia_ADL_TextureFilter Arcadia_ADL_TextureFilter; An enumeration of texture magnification and minification filters. A texture filter identifies a technique to compute the pixel value closest to the specified uv coordinates. The values correspond to the texture filters of the engine.

The value None is used as the default value and indicates that no filter is specified and the engine's default filter is used. In ADL assets, each element is identified by a string literal of the same name, e.g. "Linear" or "Nearest".

A texture address mode identifies a technique for resolving uv coordinates that are outside of the boundaries of a texture. The values correspond to the texture address modes of the engine.

The value None is used as the default value and indicates that no address mode is specified and the engine's default address mode is used. In ADL assets, each element is identified by a string literal of the same name, e.g. "ClampToEdge" or "Repeat".

Elements

Arcadia_ADL_TextureAddressMode_ClampToEdge
